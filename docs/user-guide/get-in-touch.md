# Get in Touch

## Reporting a bug or requesting a feature

[Open a GitHub issue](https://github.com/CDCgov/tostadas/issues/new/choose) — choose the template that fits your situation:

- **Bug report (user)** — something isn't working as expected
- **Feature request (user)** — you'd like new functionality
- **Bug report (maintainer/collaborator)** — internal issue
- **Feature request (maintainer/collaborator)** — internal enhancement

Fill out all fields in the template. The more detail you provide (error messages, `nextflow run` command, `.command.err` output), the faster we can help.

Allow a few days for response. If a week has passed with no activity on an urgent issue, start a [GitHub Discussion](https://github.com/CDCgov/tostadas/discussions) referencing the issue number and reason for urgency.

## Before opening an issue

Check [Troubleshooting](troubleshooting.md) first — common problems and fixes are documented there.
